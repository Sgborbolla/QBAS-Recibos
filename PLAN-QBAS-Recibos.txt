1. OBJETIVO
----------------------------------------------------------------
Generador de Recibos universal que se compile a:
  - .exe  para PC (Windows) via Neutralinojs (servidor localhost)
  - .apk  para Android via Capacitor (WebView 100% offline)
Sin demo web. Sin marca de agua. Sin links externos.
Todo compilado automaticamente con GitHub Actions al hacer push.

2. NOMBRE
----------------------------------------------------------------
Archivos finales : QBAS-Recibos.exe  /  QBAS-Recibos.apk
Titulo interno ES: QBAS - Generador de Recibos
Titulo interno EN: QBAS - Receipt Generator

3. CARACTERISTICAS
----------------------------------------------------------------
- Bilingue ES / EN con selector visible y cambio instantaneo.
- Preferencia de idioma guardada en localStorage (por defecto ES).
- 100% offline (localhost en .exe / WebView embebido en .apk).
- Sin login, sin backend, sin base de datos externa.
- Sin demo, sin marca de agua, sin enlaces externos.

4. FUNCIONALIDADES
----------------------------------------------------------------
- Formulario: Emisor (nombre, direccion, telefono, logo opcional)
- Cliente (nombre, direccion, telefono - opcionales)
- Datos del recibo: fecha y folio (automatico)
- Tabla de conceptos: Cantidad, Descripcion, Precio Unitario
  * Agregar fila / Eliminar fila
  * Subtotal por fila automatico (cantidad * precio)
- Totales: Subtotal, Descuento (monto o %), Total Neto automatico
- Notas / pie de recibo (texto libre)
- Logo opcional (solo local, no se sube a ningun servidor)
- Folio automatico: se genera e incrementa (+1) al limpiar/nuevo
- Guardado local de campos en localStorage
- Imprimir / Guardar PDF (window.print), oculta UI al imprimir

8. STACK
----------------------------------------------------------------
- Neutralinojs  -> .exe (ligero, localhost)
- CapacitorJS   -> .apk (WebView offline)
- GitHub Actions-> compila ambos al hacer push

9. GITHUB ACTIONS (.github/workflows/build.yml)
----------------------------------------------------------------
Job 1 (.exe):
  - Instalar Node + @neutralinojs/neu
  - Preparar recursos desde src/
  - neu build --release  (Windows)
  - Artefacto: QBAS-Recibos.exe
Job 2 (.apk):
  - Instalar Node
  - npm install en android/ ; npx cap sync android
  - Configurar JDK + Android SDK
  - ./gradlew assembleRelease
  - Artefacto: QBAS-Recibos.apk
